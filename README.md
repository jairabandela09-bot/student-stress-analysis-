# student-stress-analysis-

Overview:
An exploratory data analysis investigating relationships among student stress, sleep, screen time, study hours, caffeine intake, physical activity, and academic pressure.

Tools: 
Python, pandas, Matplotlib 

Analysis Includes: 
- Descriptive statistics
- Distribution analysis
- Data visualization
- Correlation analysis
- Interpretation of unexpected data patterns
- Discussion of potential dataset limitations

Find CSV at: https://www.kaggle.com/datasets/arpitabhaskar/student-stress-sleep-and-screen-time-dataset?resource=download
